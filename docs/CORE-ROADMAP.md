# BONS Core Product Roadmap

## Epics

### A. Foundation
- Product principles and acceptance criteria
- Domain model and data contracts
- Responsive navigation and user journeys

### B. Event discovery and organizer tools
- Event registration and editing
- Search and filtering
- Map and calendar
- Organizer profiles

### C. Participation and collection
- Event check-in
- Stamps and medals
- Participant history

### D. Trust and launch
- Provenance, verification, corrections, and moderation
- PWA and deployment
- Field validation with participants and organizers

## Core implementation issues

1. Define BONS product principles and MVP acceptance criteria.
2. Define event, venue, organizer, participant, check-in, stamp, medal, badge, and sponsor data model.
3. Design responsive navigation and participant/organizer journeys.
4. Implement event registration and editing.
5. Implement event listing, search, and filters.
6. Implement map and calendar views.
7. Implement organizer profiles and ownership verification.
8. Implement QR event check-in with replay/duplicate protection.
9. Implement participant stamps, event medals, and collection history.
10. Implement event provenance, verification, correction, reporting, and moderation.
11. Build PWA deployment and baseline observability.
12. Run field validation with organizers and participants; document findings and next priorities.

## MVP demo journey

Organizer registers an event → participant discovers it in search/map → participant opens event details → participant checks in at the venue → participant receives an event medal → participant finds a dance reference to practice.
